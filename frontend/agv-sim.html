DWG 转换组件缺失

导入 .dwg 图纸需要在本机安装并取得适用许可的 ODA File Converter（命令行自动调用，无需手动打开）。

任选一种方式：

1）下载并安装 ODA File Converter（Windows x64），安装后重新点导入即可，无需重启本工具：
https://www.opendesign.com/guestfiles/oda_file_converter

2）在 CAD 中打开图纸，「另存为」选择 AutoCAD 2013 DXF (*.dxf)，然后直接导入 DXF。

注：ODA File Converter 官方许可限定非商业场景使用，商业用途请遵循 ODA 许可条款。
